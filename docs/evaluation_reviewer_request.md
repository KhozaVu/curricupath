## Suggested request

Subject: Request for independent review of CurricuPath academic-advising cases

We are evaluating CurricuPath, a Wits EFA03/EFA04 academic-advising prototype. We are
requesting independent assistance so that the developers do not define and judge the
same curriculum cases.

The requested work is:

1. **22-26 September:** draft a small concealed set of synthetic eligibility cases
   before seeing the developers' scenario list;
2. **27 September-1 October:** label synthetic cases as `eligible`, `ineligible`, or
   `manual_review_required`, with a brief source-backed reason;
3. **27 September-1 October:** help adjudicate disagreements where required; and
4. **5-7 October:** if serving as a grounding judge, label whether anonymised atomic
   answer claims are supported, unsupported, or unverifiable from the supplied source.

The cases contain no real student records. Reviewers will receive the frozen protocol,
definitions, authoritative source pages, workload estimate, and conflict-of-interest
statement before agreeing. System outputs will not be shown during reference labelling.

## Independence record

Record the following in `experiments/evaluation/v2_5/personnel.json` only after the
person agrees:

- name or approved study identifier;
- affiliation/project role;
- developer or non-developer status;
- case-author or case-labeller role;
- declared conflicts;
- confirmed hours for each activity; and
- agreement date.

Reviewer-authored concealed cases should be labelled by a second qualified person where
possible. If this cannot be arranged, the limitation must remain explicit in the final
report. At least one grounding judge must be a non-developer or Experiment B remains a
pilot.
